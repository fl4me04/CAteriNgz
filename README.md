## 🍔 What is CAteriNgz?
CateriNgz is one of my project from Human Computer Interaction (HCI) subject in my university. CAteriNgz is a website that represents an online catering business. It showcases the products offered, customer testimonials, and some information about CAteriNgz. This project was built using HTML, CSS, and a bit of JavaScript, with the aim of developing only the front-end as part of a final project for a Human-Computer Interaction (HCI) course.
